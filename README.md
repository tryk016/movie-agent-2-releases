# Movie Agent 2 — wydania

Oficjalne repozytorium dystrybucyjne Movie Agent 2. Zawiera wyłącznie opublikowane instalatory, manifesty aktualizacji, podpisy, sumy SHA-256 i informacje o wydaniach. Kod źródłowy jest przechowywany w osobnym prywatnym repozytorium.

**Nie opublikowano jeszcze instalatorów.** Kandydaci są w trakcie testów. Wydania BETA będą oznaczone jako pre-release, a STABLE jako zwykłe wydania.

Instalatory Windows EXE i Linux DEB będą dostępne w [GitHub Releases](https://github.com/tryk016/movie-agent-2-releases/releases). Strona Movie Agenta zawiera tylko odnośniki do GitHuba; nie hostuje ani nie przekazuje pakietów instalacyjnych.

Movie Agent 2 jest prywatną aplikacją dla maksymalnie trzech zaproszonych użytkowników. Samo pobranie instalatora nie daje dostępu do kont ani danych.

Nie traktuj plików testowych lub niepodpisanych kandydatów jako gotowego wydania. Publiczny klucz Ed25519 wydawcy jest w [release-signing-public.json](release-signing-public.json). Jego odcisk SHA-256: `043cebfc1c4eb5db7846d4c40748cfe466ebc0b5d5b6f1841a79244163df3d3e`. Instrukcje weryfikacji pakietów pojawią się razem z pierwszym podpisanym wydaniem. Podpis manifestu nie jest certyfikatem Authenticode Windows.
